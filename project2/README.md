# 하이어톡 채용플랫폼 활성화 전략 제안

유저 로그 데이터를 기반으로 채용플랫폼 활성화 전략을 제안한 프로젝트입니다.

## 1. 전처리 및 데이터마트 구축
SQL로 결측치, 중복값, 이상치를 제거해 정제 테이블 구축
- `log_2022_clean` : 로그 8,751,565행, 순유저 17,018명
- `log_2023_clean` : 로그 6,612,114행, 순유저 15,261명

**정제 세부 사항**
- `on_bad_lines='skip'`으로 파싱 불가한 행 약 12만 건 제외
- timestamp 변환(따옴표 및 UTC 제거) / date 변환 과정에서 약 28건 제외
- URL 정제 및 분류: 딕셔너리에 명시적으로 매핑된 URL만 분류하고, 나머지는 미분류로 처리

## 2. RFM 분석으로 유저 세그먼트 도출
네트워킹 × 구직활동 기준 6개 세그먼트 분류 (핵심형·탐색형·목적형·관망형·휴면·이탈)

## 3. 세그먼트별 마케팅 전략
- **전체 유저**: 가입 당일 프로필(경력·전문분야·이력서) 작성 유도
- **탐색 구직자**: 북마크 후 미지원 유저 대상 지원 유도 알림 + 제출 단계 리워드
- **관망형 유저**: 관심사 기반 인맥 추천, 조회·저장 이력 리마인드
