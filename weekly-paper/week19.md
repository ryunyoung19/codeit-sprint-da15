# 위클리페이퍼 **Week19**

## Q. 편의점 매출 데이터를 분석했더니 매주 금·토에 매출이 급증하는 패턴이 보입니다. 이를 시계열 관점에서 어떻게 설명하겠나요? 이 패턴을 예측 모델에 반영하려면 어떻게 해야 할까요?

### 1. 현상 설명

- 금·토 매출 급증 = **주간 계절성(Weekly Seasonality, 주기=7)**
- 근거: **STL** 분해로 확인, **ACF plot**에서 lag=7,14,21 스파이크 확인
- 원인: 주말 시작 **요일 효과(day-of-week effect)**

### 2. 모델 반영 방법

| 단계 | 내용 |
| --- | --- |
| 전처리 |   • 일 단위 리샘플링
  • 결측치는 **직전 주 동일 요일 값**으로 대체 (계절성 정보 그대로 보존) |
| 정상성 검정 |   • ARIMA/SARIMA는 정상성을 가정
  • **ADF test** → 비정상이면 차분(d=1) or 계절차분(D=1, lag=7) |
| 베이스라인 |   **• Seasonal Naive** (전주 동요일 값)
  • 비교 : Naive (바로 전날 값을 그대로 씀) |
| 모델링 |   **• SARIMA(p,d,q)(P,D,Q,m=7 = 계절주기)** |
| 대안 모델 |   **• Prophet** (요일별 계절성을 자동으로 반영해주는 라이브러리) |
| 검증 |   • 시간순서 보존한 Train/Test split
  • 평가지표는 RMSE, MAPE 등을 사용 |

### 3. 한 줄 요약

> 주기 7일의 주간 계절성 → ACF/STL로 검증 → SARIMA(m=7) 또는 Prophet으로 반영 → 시간순서 보존한 Train/Test 평가
