## 1. SQL에서 JOIN은 왜 필요한가요? INNER JOIN과 LEFT JOIN의 차이를 실제 업무 예시를 들어 설명해 보세요.

- JOIN은 두 개 이상의 테이블을 하나로 결합할 때 사용. 실무에서는 데이터가 여러 테이블에 나뉘어 저장되는 경우가 많기 때문에, 필요한 정보를 함께 조회하려면 JOIN이 필수적.
- INNER JOIN은 두 테이블의 교집합, 즉 양쪽 모두에 존재하는 데이터만 추출하는 방식.
- LEFT JOIN은 왼쪽 기준 테이블의 데이터를 모두 유지하면서, 오른쪽 테이블에 매칭되는 값이 없으면 NULL로 채우는 방식.
- stores(가게 테이블, 운영 + 폐업 포함)와 orders(주문 테이블, 운영 중인 가게만 존재)가 있다고 가정하면, 운영 중인 가게만 보고 싶을 때는 INNER JOIN을 사용해 주문이 존재하는 가게만 조회할 수 있음. 반면 폐업한 가게까지 포함한 전체 가게 현황을 보고 싶다면 LEFT JOIN을 사용해 주문이 없는 가게는 NULL로 표시하면서 전체를 조회.
- 정리하면, **기준 테이블의 데이터를 모두 유지하고 싶을 때는 LEFT JOIN, 양쪽 테이블에 모두 존재하는 데이터만 필요할 때는 INNER JOIN**을 사용.

|  | INNER JOIN | LEFT JOIN |
| --- | --- | --- |
| 결과 범위 | 양쪽 모두 존재하는 데이터만 | 왼쪽 테이블 전체 유지 |
| 매칭 안 될 때 | 행 제외 | NULL로 표시 |
| 사용 상황 | 교집합 데이터만 필요할 때 | 누락 없이 전체를 봐야 할 때 |
| 예시 | 주문 있는 가게만 조회 | 폐업 가게 포함 전체 조회 |

## 2. Window 함수(윈도우 함수)는 어떤 문제를 해결하기 위해 존재하나요? GROUP BY와 비교해서 설명하고, 실제로 활용한 사례나 활용 가능한 시나리오를 하나 소개해 주세요.

- Window 함수는 GROUP BY로는 해결하기 어려운 문제를 위해 존재. GROUP BY는 집계를 하면 행이 그룹 단위로 합쳐져서 개별 행의 정보가 사라짐. 반면 Window 함수는 집계 결과를 계산하면서도 원본 행을 그대로 유지할 수 있음.
- 이커머스에서 각 고객의 개별 구매 금액과, 그 고객이 속한 등급 내 평균 구매 금액을 한 행에 함께 보고 싶은 경우, GROUP BY만 사용하면 개인 구매 금액이 사라지기 때문에 서브쿼리나 JOIN을 써야 해서 쿼리가 복잡.
- 하지만 `AVG() OVER (PARTITION BY grade)`처럼 Window 함수를 사용하면 개별 행을 유지하면서 그룹 평균을 함께 볼 수 있어 훨씬 간결하게 해결.
- 순위 계산이나 누적 합계처럼 **행 간 비교가 필요한 상황에서 특히 유용.**

|  | GROUP BY | Window 함수 |
| --- | --- | --- |
| 결과 행 수 | 줄어듦 | 원본 유지 |
| 개별 행 접근 | 불가 | 가능 |
| 순위/누적 계산 | 어려움 | 용이 |

## 3. 허위 지표(Vanity Metric)와 실질 지표(Actionable Metric)의 차이는 무엇인가요? 본인이 알고 있는 서비스를 예시로 들어, 허위 지표로 보일 수 있는 것과 그것을 대체할 실질 지표를 하나씩 제안해 보세요.

- 허위 지표는 숫자가 커 보여서 좋아 보이지만, 실제로 어떤 행동을 해야 할지 방향을 제시해 주지 못하는 지표.
- 반면 **실질 지표는 특정 액션을 취했을 때 변화를 명확히 측정할 수 있고, 개선 방향을 직접적으로 알려주는 지표.**
- 유튜브 총 조회수는 대표적인 허위 지표. 조회수가 1,000만이라도 그 시청자들이 채널에 관심이 생겼는지, 그냥 이탈했는지는 알 수 없기 때문. 이를 대체할 실질 지표로는 영상 시청 후 구독 전환율. 이 지표는 콘텐츠가 실제로 팬을 만들어내고 있는지를 직접 보여주기 때문에, 어떤 유형의 콘텐츠를 더 만들어야 할지 전략적인 판단을 내리는 데 훨씬 유용.

|  | 허위 지표 (Vanity Metric) | 실질 지표 (Actionable Metric) |
| --- | --- | --- |
| 정의 | 보기엔 좋지만 의사결정에 무의미 | 행동과 개선 방향을 직접 제시 |
| 예시 (유튜브) | 총 조회수 | 시청 후 구독 전환율 |
| 한계/강점 | 이탈/관심 여부를 알 수 없음 | 콘텐츠 전략 수립에 직결됨 |
