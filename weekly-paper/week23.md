# 위클리페이퍼 Week23

### Q. 데이터 분석팀이 로컬 서버(온프레미스)에서 클라우드로 분석 환경을 이전하려 합니다. 이 결정의 어떤 장점이 가장 큰 이유가 될 것 같나요? 반대로 클라우드 전환을 고민하게 만드는 우려 사항은 무엇이 있을까요?

### 클라우드 전환의 가장 큰 장점

확장성과 비용 구조 전환이 핵심

- **필요할 때만 리소스 사용**: 온프레미스는 최대 부하 기준으로 서버를 사놔야 하지만, 클라우드는 대용량 작업 때만 스케일업하고 줄일 수 있어 워크로드가 들쭉날쭉한 분석팀에 유리
- **CAPEX → OPEX 전환**: 서버 구매·유지보수 비용이 사라지고 쓴 만큼만 지불
- **운영 부담 감소**: S3, Glue, Airflow 같은 매니지드 서비스가 패치·백업·장애 대응을 대신해줘서 분석 자체에 집중 가능

### 반대로 우려되는 지점

- **비용 예측 어려움**: 쿼리 최적화 없이 대용량 스캔을 반복하면 온프레미스보다 비용이 커질 수 있음
- **보안·규제 이슈**: 금융 데이터를 외부 클라우드에 저장할 경우 데이터 주권 및 망분리 규정 위반 가능성 검토 필요
- **벤더 종속**: 특정 클라우드 서비스에 맞춰 시스템을 구축하면 이후 타 업체로 전환하기 어려움
- **네트워크 지연**: 온프레미스와 클라우드를 함께 운영하는 하이브리드 구조에서는 데이터 전송 지연 및 비용 발생
- **학습 곡선**: 클라우드 신규 개념(IAM, VPC 등) 습득에 시간이 소요되어 전환 초기 생산성 저하 가능
